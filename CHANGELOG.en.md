# Changelog

English version of `CHANGELOG.md`, shown at `/en/changelog/`. Keep the same versions and dates as `CHANGELOG.md`;
newest first, headings are "## version - date". See `RELEASING.md` for how to cut a release.

## Unreleased

## 2.0.0 - 2026-10-16

- The site moved to **bluz.dev** on Cloudflare Pages; every page of the old fantasybluz.github.io address forwards to the new one
- **Redesigned** after Apple's design language: a thin translucent black nav bar, sections alternating white, light gray, and black, a single blue accent, and a full-screen menu on phones
- New **link-preview cards** when the site is shared on LINE or Facebook, one per language
- Side projects: added **CoCo**, the **Convenience Store Cocktail Slots**, and **Taiwan Random Trip**, with screenshots and live-site links
- The footer shows the **version number**, which opens this **changelog**

## 1.4.0 - 2026-10-07

- Side projects: added **mneme** (a personal knowledge base with a local LLM, semantic search, and cited answers) and **llm-operator** (a Kubernetes operator for running local LLMs)
- Side projects can show **screenshots** and GitHub or live-site links
- Skills: added Next.js, Turborepo, Helm, GitHub Actions, Kubebuilder, and more, plus a new **AI / LLM** category

## 1.3.0 - 2026-09-30

- The English version has its own address, **/en/**, so search engines index both languages
- Every page is **prerendered to full HTML** at build time, so content shows without waiting for JavaScript, and search results and link previews are more complete
- New **Side Projects** section: Retail Management System, llm-bench, and Atum

## 1.2.0 - 2026-03-18

- A new **dark theme** with a dot pattern, glow, and meteor effects in the background

## 1.1.0 - 2026-02-25

- New **Experience** and **Credentials** sections: research projects, education, competitions, and publications
- Site description and sitemap for search engines and social sharing
